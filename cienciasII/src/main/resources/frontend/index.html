Plataforma Educativa de Estructuras y Organización de Datos

Un espacio interactivo para estudiar, experimentar y visualizar paso a paso algoritmos de búsqueda, funciones de transformación de claves (hashing) y, próximamente, algoritmos sobre grafos.

Objetivo educativo

Esta plataforma no se limita a ejecutar algoritmos: busca que el estudiante entienda qué datos existen, qué algoritmo se está ejecutando, qué paso se realiza en cada momento, qué comparación se hace, qué resultado se obtiene y cuál es la complejidad temporal asociada a cada técnica.

Temas disponibles

Búsquedas internas y externas Genera bloques de claves, ordénalos y compara la búsqueda secuencial contra la búsqueda binaria, paso a paso. Transformación de claves Calcula funciones hash (módulo, cuadrado, truncamiento, plegamiento) y observa cómo se resuelven las colisiones.
Grafos Próximamente: representación, recorridos (BFS/DFS) y algoritmos de árboles de expansión mínima (Prim, Kruskal).
