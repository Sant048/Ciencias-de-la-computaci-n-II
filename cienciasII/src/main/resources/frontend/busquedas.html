Búsquedas internas y externas

Conceptos básicos

Una búsqueda de información consiste en localizar un dato (clave) dentro de un conjunto de datos. Según dónde estén almacenados esos datos, la búsqueda se clasifica en:

Búsqueda interna: los datos residen en memoria principal (RAM), por lo que el acceso a cada elemento es prácticamente inmediato.

Búsqueda externa: los datos residen en memoria secundaria (disco), por lo que cada acceso a un elemento implica una operación de entrada/salida, mucho más costosa que un acceso en memoria interna.

Esta herramienta trabaja con búsqueda interna (los bloques de claves se mantienen en memoria del navegador), pero los conceptos de comparación y complejidad son igualmente aplicables a la búsqueda externa.

3. Búsqueda secuencial

Recorre el bloque desde el primer elemento, comparando uno a uno, sin requerir orden previo.

4. Búsqueda binaria

Para utilizar búsqueda binaria, las claves deben estar ordenadas. Usa el botón "Ordenar" en la sección anterior.

5. Complejidad temporal

Algoritmo Mejor caso Caso promedio Peor caso
Búsqueda secuencial O(1) O(n) O(n)
Búsqueda binaria O(1) O(log n) O(log n)

La búsqueda binaria necesita datos ordenados porque en cada paso descarta la mitad del rango de búsqueda comparando con el elemento central; esa decisión solo es válida si se garantiza que todos los elementos a un lado son menores (o mayores) que el central, lo cual únicamente se cumple si el bloque está ordenado.
