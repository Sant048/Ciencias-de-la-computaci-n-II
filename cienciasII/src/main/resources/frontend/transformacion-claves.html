Transformación de claves

Conceptos básicos

Una tabla hash es una estructura de datos que permite acceder a un valor casi directamente a partir de su clave, utilizando una función de transformación de claves (función hash) que convierte la clave en un índice dentro de la tabla.

Una colisión ocurre cuando dos claves distintas producen el mismo índice al aplicar la función hash. Las colisiones son inevitables cuando el número de claves posibles supera el tamaño de la tabla, y por eso existen métodos de resolución de colisiones, que definen dónde ubicar la clave cuando la posición calculada ya está ocupada.

3. Métodos de resolución de colisiones

Lineal: h(k, i) = (h(k) + i) mod m. Se prueba la siguiente posición, una a una.

Cuadrática: h(k, i) = (h(k) + c1·i + c2·i²) mod m. Los saltos crecen cuadráticamente (c1 = c2 = 1 en esta implementación).

Doble Hash: h(k, i) = (h1(k) + i·h2(k)) mod m, usando una segunda función hash para calcular el salto.

Anidados: cada posición admite un pequeño arreglo de hasta 2 claves antes de recurrir a sondeo lineal como desbordamiento.

Encadenamiento: cada posición contiene una lista sin límite de tamaño; nunca se considera "tabla llena".
